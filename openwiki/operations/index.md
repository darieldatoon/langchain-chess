# Files

- [Deployment and the image build](deployment.md) - How CI gates merges and how four workflows ship from main — deploy.yml (Agent Server image for the langchain-chess agent's production environment, no UI), pages.yml (web UI to GitHub Pages, skipped until VITE_API_URL is set), deploy-review.yml (review app) and deploy-grader.yml (grader sandbox snapshot) — with a tip SHA resolved inside a queued concurrency lock, on.push path filters, and a superseded check. Also how langgraph.json builds the image from the uv workspace, why dockerfile_lines lists member pyproject.toml files while workspace sources live only in the root pyproject.toml, and why evals changes never redeploy anything.
- [Local development](local-development.md) - How the repo's single mise.toml supplies every tool and task (setup, dev:web with port checks and readiness, dev:tui, dev:uci, dev:review, check, test, test:e2e, test:live, test:uci, eval tasks, generate:settings, probe:efforts, deploy, agent:tag, wiki tasks), how .env is loaded explicitly, how Socket Firewall (sfw) wraps dependency installs, what the lefthook git hooks enforce, common troubleshooting fixes, and how the OpenWiki update workflow runs.
- [Runtime behavior and failure modes](runtime-behavior.md) - How a turn of the chess graph (deployed as langchain-chess-app) fails and recovers at runtime. Covers stalled-stream retries, provider errors (context overflow, rejected reasoning effort), illegal-reply retries, the pending-turn resume path, System 1 ranking failures, settings validation, memory eligibility, the System 1 HTTP client pools' lifetime, what the web UI and the UCI adapter do on failure, sign-in failures (refused or expired sign-in, unreachable server), and how to read LangSmith traces and recorded cost against the code.
