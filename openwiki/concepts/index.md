# Files

- [The middleware contract](middleware-contract.md) - How chess extensions plug into create_chess_agent. Covers the ChessMiddleware helpers, the write guard that gives each hook a detached copy of state and checks every write, the rules for allowed_moves, proposal, candidates and fallback_move, per-agent seed binding, and the idempotent before_model with a frozen per-turn decision that SystemOneMiddleware uses.
- [Model specs, LLM Gateway and cost](models-gateway-and-cost.md) - How chess agents name models (init_chat_model specs and the langsmith: gateway provider), how the shared chat_model builder sizes output budgets, reasoning effort and input-limit profiles, how CallRecorder captures every provider response, and how calls are priced locally with genai-prices and summed into a possibly incomplete turn cost.
- [Prompt and memory](prompt-and-memory.md) - How ChessCore builds each move request from a filtered view of stored messages plus a freshly rendered position block, how show_legal_moves and candidates appear in it, what memory none/summarize let the model see, how ChessSummarization is configured and validated (including the shared chat_model input-limit profiles and the summarize eligibility check), and how context overflow becomes ContextBudgetError.
- [The client-readable state record](state-record.md) - The ChessState keys clients may read (start_fen, moves, plies, turns, outcome, error, plus the Agent Server's setup), the Ply, TurnRecord and Call shapes, why messages and private channels are excluded, the two input keys (messages and position with restrict), and the one-run-one-turn, one-thread-one-game rules, including which commands are rejected.
