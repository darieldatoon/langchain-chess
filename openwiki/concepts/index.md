# Files

- [Decisions and measurements](decisions.md) - Design choices in langchain-chess that look like gaps (no Anthropic prompt caching, the removed `full` memory mode, memory now a plain on/off switch) with the measured numbers behind them and the conditions under which to revisit them. Also notes which defaults, such as the System 1 threshold, have no recorded measurement.
- [The middleware contract](middleware-contract.md) - How chess extensions plug into create_chess_agent. Covers the ChessMiddleware helpers, the write guard that gives each hook a detached copy of state and checks every write, the rules for allowed_moves, proposal, candidates and fallback_move, per-agent seed binding, the core-owned StallRetry that stays innermost after all user middleware, and the idempotent before_model with a frozen per-turn decision that SystemOneMiddleware uses.
- [Model specs, the LLM Gateway and cost](models-gateway-and-cost.md) - How chess agents name models (init_chat_model specs and the langsmith: gateway provider), the default models, which models take a reasoning effort (the probed efforts.json snapshot), how model_kwargs resolve into the shared chat_model builder's output budget and input-limit profile, how CallRecorder captures and locally prices every provider response (genai-prices plus the OpenAI Decisions rate), why stalled calls record nothing, and when a turn's cost is incomplete.
- [Prompt and memory](prompt-and-memory.md)
- [Settings and model arguments](settings-and-model-arguments.md) - The versioned CoreSettings/ChessContext opponent schema shared by the agent server, CLI, web app and evals. Covers migrate/resolve and merge order (assistant context, then configurable, with null meaning reset), how model_kwargs are checked on each surface, codegen into packages/chess-ui, opponent settings files, and the server's environment ServerSettings, including OAuth sign-in settings for which a blank value means unset.
- [The state record](state-record.md) - The ChessState keys clients may read (start_fen, moves, plies, turns, outcome, error, draw_offers, plus middleware keys such as the Agent Server's setup and System 1's systemone_live), the Ply, TurnRecord, Call and DrawOffer shapes, why messages and private channels are excluded, the two input keys (messages and position with restrict) including the resign and draw chat commands, and the one-run-one-turn, one-thread-one-game rules.
