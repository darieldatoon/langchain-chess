# Files

- [Agent Server graph and HTTP surface](agent-server.md) - How langgraph.json wires the `chess` graph factory, the "Sign in with LangSmith" auth handler and a custom FastAPI app into the LangGraph Agent Server; how make_graph builds runs and runless reads over the shared build_agent with a fixed topology, how a run's ChessContext is resolved, how GameSetupMiddleware records a game's settings, the shared System 1 client pools closed by the app's lifespan, ServerSettings, the single GET /model-facts route and the rule that custom routes must avoid Agent Server API paths, and how the GitHub Pages web client calls the server.
- [Sign in with LangSmith: authentication and access control](langsmith-sign-in.md) - How the web app signs users in with LangSmith OAuth (oidc-client-ts, PKCE, optional SSO slug and organization choice) or an API key, how it stores and checks the session, and how the Agent Server auth handler verifies LangSmith EdDSA JWTs and admits only this OAuth client and organization.
- [Terminal UI (lcchess play)](terminal-ui.md) - How `lcchess play` runs a Textual game against an in-process chess agent, laid out like the web app. Covers the app state and run workers, the board widget, the New Game screen and opponent setup, the Last Reply panel, browsing, resign/draw, PGN/FEN/Lichess export, opening names and themes, plus the CLI's shared flags, the `--config`/`--reset` overlay, `build_agent` and `run_config`.
- [UCI engine adapter (lcchess uci)](uci-engine.md) - How `lcchess uci` wraps a langchain-chess agent as an in-process UCI engine — the one-search state machine that prints exactly one bestmove per go, soft and hard time-control deadlines, System 1 fallback picks (never a random move), bestmove 0000 forfeits, abandoned pending turns, UCI options including Config files, draw_claims "never", and the fastchess smoke test.
