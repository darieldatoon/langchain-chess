# Files

- [Agent Server graph and /ui app](agent-server.md) - How the LangGraph Agent Server builds the `chess` graph (make_graph, the runless shape(), build_graph over the shared build_agent in libs/systemone, a fixed topology for every policy), how a run's ChessContext is resolved from assistant context and `configurable` through migrate/resolve, how GameSetupMiddleware records a game's settings in thread state, the shared System 1 HTTP client pools (TypeSafe and OpenAI Decisions), what ServerSettings validates, and how a custom FastAPI app serves /ui/config, /ui/model and (locally) the built web UI, while the hosted UI lives on GitHub Pages.
- [Terminal UI (lcchess play)](terminal-ui.md) - How `lcchess play` runs a Textual game against an in-process chess agent, laid out like the web app. Covers the app state and run workers, the board widget, the New Game screen and opponent setup, the Last Reply panel, browsing, resign/draw, PGN/FEN/Lichess export, opening names and themes, plus the CLI's shared flags, the `--config`/`--reset` overlay, `build_agent` and `run_config`.
- [UCI engine adapter (lcchess uci)](uci-engine.md) - How `lcchess uci` wraps a langchain-chess agent as an in-process UCI engine — the one-search state machine that prints exactly one bestmove per go, soft and hard time-control deadlines, System 1 fallback picks (never a random move), bestmove 0000 forfeits, abandoned pending turns, UCI options including Config files, draw_claims "never", and the fastchess smoke test.
