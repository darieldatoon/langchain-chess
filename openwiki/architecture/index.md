# Files

- [Package map and dependency direction](package-map.md) - The Python (uv) and JavaScript (pnpm) packages in langchain-chess, which way dependencies may point (systemone -> chess; cli, server and evals -> both; web/review/reports -> chess-ui), the shared build_agent in libs/systemone, the Python-to-TS settings codegen, the runtime HTTP links, and which layer a new feature belongs in.
- [System 1 (SystemOneMiddleware)](system-one.md) - How SystemOneMiddleware ranks the allowed moves with a System 1 classifier (Jev over TypeSafe, or an OpenAI Decisions model, via GatewayRanker), gates on margin or confidence to either play the top move or suggest a shortlist, runs a seeded tournament when a capped classifier gets more options than one request holds, behaves when ranking fails with and without an LLM, publishes its decision live, and is wired per opponent policy by the shared build_agent in libs/systemone.
- [Turn lifecycle](turn-lifecycle.md) - How create_chess_agent assembles its fixed middleware stack (including fixed_topology and the core-owned StallRetry) and how ChessCore plays at most one turn per run, covering command classification, resign and draw control commands, invocation and opened_turn bookkeeping, pending, abandoned, committed and terminal turns, reply parsing, illegal-move retries and forfeits, stall retries, the forced-move shortcut, failed provider calls, provider error translation (ContextBudgetError, ReasoningEffortError), atomic finalization and draw claims.
- [Web frontends (apps/web, apps/review, packages/chess-ui)](web-frontends.md) - How the React play UI (apps/web) drives the chess graph through useStream with one thread per game, starts games from any position, continues any game from the setup recorded in its thread, and exports settings and PGN; how its render.html page draws positions-dataset runs inside LangSmith over postMessage; how the LangSmith review app (apps/review) reads and launches game grading; and how both share packages/chess-ui, including the settings schema generated from the Python ChessContext, inside a Vite+ pnpm workspace.
