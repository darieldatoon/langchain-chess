# Files

- [Package map and dependency direction](package-map.md) - The Python (uv) and JavaScript (pnpm) packages in langchain-chess, which way dependencies are allowed to point (systemone -> chess, cli and server -> both, web/review -> chess-ui), and a guide to which layer a new feature belongs in.
- [System 1: SystemOneMiddleware, ranker and tournament](system-one.md) - How SystemOneMiddleware ranks the allowed moves with a System 1 classifier (SemIf or Jev via GatewayRanker), gates on margin or confidence to either play the top move or suggest a shortlist, runs a seeded tournament for more options than one request holds, and behaves when ranking fails with and without an LLM.
- [The agent loop: ChessCore and the turn lifecycle](turn-lifecycle.md) - How create_chess_agent assembles its middleware stack and how ChessCore plays at most one turn per run, covering command classification, pending, abandoned, committed and terminal turns, reply parsing, illegal-move retries and resignation, the forced-move shortcut, atomic finalization, draw claims and ContextBudgetError.
- [Web frontends: apps/web, apps/review and packages/chess-ui](web-frontends.md) - How the React play UI (apps/web) drives the chess graph through useStream with one thread per game, how the LangSmith review app (apps/review) reads threads and game_review feedback, and how both share packages/chess-ui as TypeScript source inside a Vite+ pnpm workspace.
